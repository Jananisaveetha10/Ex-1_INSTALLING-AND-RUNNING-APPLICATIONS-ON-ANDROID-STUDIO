# Ex-1_INSTALLING-AND-RUNNING-APPLICATIONS-ON-ANDROID-STUDIO
## NAME: JANANI S
## REG NO: 212224040127

### Aim
To install Android Studio, create a new Android application, build the project, and successfully run the application on an Android Emulator or a physical Android device.

### Software Requirements
1. Android Studio
2. Java Development Kit (JDK)
3. Android SDK
4. Android Emulator or Android Device
5. Windows/Linux/macOS

### Procedure
1. Install Android Studio and the required SDK components.
2. Launch Android Studio.
3. Create a new project using the Empty Views Activity template.
4. Enter the application name, package name, and select the programming language (Java/Kotlin).
5. Click Finish to generate the project.
6. Allow Gradle to download the required dependencies and complete project synchronization.
7. Create or start an Android Virtual Device (AVD), or connect a physical Android phone with USB debugging enabled.
8. Click the Run (▶) button in Android Studio.
9. Select the target device or emulator.
10. Wait for the application to build, install, and launch.
